## 📖 About The Project

FakeShield is a comprehensive fake news detection platform that combines multiple AI techniques to analyze content credibility. It uses OCR, visual analysis, metadata inspection, and linguistic pattern recognition to determine if content is **Real**, **Suspicious**, or **Fake**.

### ✨ Key Features

- 🖼️ **Image Analysis** - Upload images and extract text using OCR (Tesseract)
- 📰 **News Text Analysis** - Detect fake news patterns in written content
- 🔗 **URL Analyzer** - Check credibility of news websites
- 📊 **Multi-Factor Scoring** - Combines visual, metadata, text, and OCR scores
- 🌍 **Multi-Language Support** - Analyze content in multiple languages
- 📈 **Dashboard** - View analysis history and statistics
- 🤖 **Telegram Bot** - Access FakeShield through Telegram
- 🎨 **Modern UI** - Beautiful, responsive interface with dark theme
